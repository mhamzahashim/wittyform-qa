## Environment and external-service requirements observed

`.env.example` and source code show dependencies on Supabase, Clerk, Resend/email, AI providers, Pinecone, Stripe, Google APIs, Slack, Typeform, CalendarJet, Cloudflare/Dokploy, OpenRouteService/Google Maps, reCAPTCHA/hCaptcha, Meta Pixel/CAPI, Google Ads, Shopify/Green API, Upstash, and multiple feature flags.

Manual QA must not expose secrets. Any test requiring unavailable credentials is labeled **Setup required** and may be skipped with a note.

## Existing automated tests observed

The repository includes extensive Vitest and Playwright coverage, including but not limited to:

- public form submission, conditional logic, and validation tests
- quiz scoring/submission/leaderboard/certificate tests
- CRM, workspace, invite, API key, integrations, webhooks, payment, offline, domain, branding, and security tests
- Playwright E2E smoke/regression suites with target-safety guards that prevent accidental production mutation

Manual QA complements these suites by checking the real staging UI and external setup-dependent journeys.
